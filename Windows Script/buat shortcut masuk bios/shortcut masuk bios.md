# Buat Shortcut Untuk Masuk Ke BIOS
---

#### 1. klik kanan di dekstop, New, Shortcut
#### 2. Type the location of the item:
```shutdown /r /fw /t 00```  

kemudian Next

#### 3. Type a name for this shortcut:
```Masuk BIOS```

kemudian Finish

#### 4. Klik kanan di shortcut, Properties, Shortcut, Advanced, Centang Run as administrator, klik ok
